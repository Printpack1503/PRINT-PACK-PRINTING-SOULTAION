PRINT PACK PRINTING SOLUTION — WEBSITE

1. Unzip the archive.
2. Open index.html in Chrome to preview the website.
3. For free hosting: create an account at https://app.netlify.com/drop and drag the unzipped printpack_website folder onto the page. Netlify provides a free site address (subject to their current plan terms).
4. Alternatively upload all files to GitHub Pages or another static website host.
5. Replace assets/printpack-logo.jpg if you get a transparent high-resolution logo.
6. Replace the placeholder business address in index.html with your actual address.
7. Gallery contains designed placeholder tiles, NOT actual portfolio photos. Replace with your real work photos before promoting the site.
8. Contact form opens WhatsApp; it does not store messages or send email. WhatsApp number: +91 7600012424. Email: Printpack1503@gmail.com.
9. Fonts are loaded from Google Fonts; internet is needed for those fonts (fallback fonts work offline).
